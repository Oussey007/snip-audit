⬇ Télécharger le manifeste (manifest.xml)

Le manifeste est généré pour cette adresse : aucune modification manuelle n'est nécessaire.

Installer dans Excel
  • Excel sur le Web : Accueil → Compléments → Plus de compléments → Mes compléments → Charger mon complément → choisir manifest.xml.
  • Windows : placer manifest.xml dans un dossier partagé (catalogue approuvé), puis Fichier → Options → Centre de gestion de la confidentialité → Paramètres → Catalogues de compléments approuvés → ajouter le chemin réseau du dossier, cocher « Afficher dans le menu » → redémarrer Excel → Accueil → Compléments → Mes compléments → DOSSIER PARTAGÉ.
  • Mac : copier manifest.xml dans ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef (créer le dossier wef s'il n'existe pas), redémarrer Excel → Accueil → Compléments → Mes compléments.
  • Déploiement cabinet : l'administrateur Microsoft 365 peut publier ce manifeste pour tous (Centre d'administration → Paramètres → Applications intégrées).
Confidentialité : ce site ne contient que le code de l'outil. Les pièces justificatives sont lues sur votre poste et stockées dans le volet (IndexedDB) ; elles ne sont jamais envoyées sur Internet.
